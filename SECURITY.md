# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

- For a vulnerability in this fork or its pet-recognition changes, use
  [GitHub's private vulnerability reporting](https://github.com/lubomir-dlhy/immich/security/advisories/new).
- For a vulnerability that also affects the upstream Immich project, follow
  the [upstream security policy](https://github.com/immich-app/immich/security/policy).

Include the affected version, reproduction steps, impact, and any suggested
mitigation. Do not include real credentials, personal photos, or other private
data in the report.

Security fixes are provided for the latest release of this fork. Older
releases may need to upgrade to receive a fix.
